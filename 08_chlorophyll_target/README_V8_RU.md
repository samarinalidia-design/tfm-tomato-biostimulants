# V8: содержание хлорофилла — полное извлечение по TRAIN_DEV и обучающий датасет (2026-11-22)

Целевая переменная — содержание хлорофилла в листьях: общий, a, b. Индексы (SPAD и другие приборы) извлечены отдельно.

- **Охват:** все 169 исследований TRAIN_DEV, в которых по инвентарю есть хлорофилл: 50 из пилота и 119 из полного прогона.
- **Не входит:** тест (статьи 2024–2026) лежит в отдельном проекте и здесь не использовался.
- **Замороженные базы не изменены.** База V8 — это копия V6 с добавленными таблицами `chl_*`.

## Как извлекали

Схема та же, что в пилоте (`README_PILOT_RU.md`), с исправлениями по его итогам.

**Проходы и разбор:**
- Каждое исследование независимо извлекали два агента, проходы A и B.
- Каждое значение привязано к квитанции отрисованной страницы.
- Рисунки оцифровывались с калибровкой не меньше чем по трём делениям оси.
- Код сверял проходы (`c04`). Расхождения разбирали арбитры по оригинальному PDF: 74 исследования (16 из пилота и 58 из полного прогона), у каждого журнал решений.

**Исправления после пилота:**
- у каждого агента своя временная папка;
- после каждой группы проверялось, что выходной файл есть для каждого исследования;
- списки исследований давались через явные разделители;
- в протоколе появились правила для «arbitrary units», для столбиков a/b, сложенных один на другой, для общей исходной точки, для хлорофилла плодов и для средних только по факторам;
- сверка сравнивает флаг «во время стресса», но не для вариантов без стресса;
- агенты, остановленные лимитом API, продолжили работу с того места, где остановились; задача не перезапускалась.

**Итог по исследованиям:**
- DONE — 154.
- NO_CHLOROPHYLL_DATA — 11: хлорофилл других культур или плодов, только средние по факторам, только отношения между вариантами, «data not shown».
- BLOCKED — 4: значения есть только в приложениях, которых нет в корпусе (исследования 13, 7, 74 и D_65e9c78cc3179036).

**Значения:** 5575 значений в двух проходах; итоговых согласованных значений 2773. В итоговом согласованном наборе неразрешённых расхождений нет.

## Обучающий датасет `data/chl_train_dataset_V8.csv` / `.parquet`

Скрипт `c06_training_dataset.py`. Одна строка — один контраст, всего 2147 контрастов. Учтены все прежние ошибки:

| ошибка, найденная раньше | как учтено |

Приоритеты: напечатанный общий хлорофилл важнее суммы a + b; свежая масса > сухая > площадь листа > не указано > объём экстракта; сообщённая дисперсия > предполагаемая SE > импутированная; таблица > рисунок; SPAD > другие индексы. Из основного набора убрано 655 дублей |
| стрессовые признаки на строках без стресса (V6 B2) | Описание стресса есть только у контрастов SB_vs_S и S_vs_C, описание препарата — только там, где есть биостимулятор |
| признаки чужого варианта | Признаки взяты у того же варианта опыта в V6 (урожай и биомасса), иначе у того же опыта или исследования. Для SB_vs_S общего хлорофилла: 311 контрастов с признаками того же варианта, 2 с уровня опыта, у 86 признаков нет (их дизайн в A399 не был закодирован) |

| зависимость внутри исследования | `cv_group` = study_id, чтобы все контрасты одного исследования, включая общие контроли, были в одном фолде |

В `in_quality_core_chl` не входят контрасты со следующими флагами: EXTREME_EFFECT, нереалистичный срок, систематическое противоречие пигментов в статье, среднее с меньше чем двумя значащими цифрами, сомнительный источник, стресс не реализован (V6), препарат содержит питательные вещества (V6), n не указано |
| общий хлорофилл = a + b при перепутанных единицах | a + b считается, только если соотношение a/b от 0,5 до 10 |

## Сравнение трёх таргетов (`scripts/c09_cv_three_targets.py`)

Для всех таргетов одинаковые:
- движок V5;
- признаки REF;
- сиды 11/22/33;
- 5 внешних фолдов, сгруппированных по кластерам;
- вложенный подбор гиперпараметров;
- модели и веса.

Неопределённость оценивается бутстрепом по исследованиям. Строгий вариант кросс-валидации объединяет в один кластер исследования одной исследовательской группы (общие авторы). Причина: две работы одной группы про хлорофилл (D_a2212a2541890542, D_aab5aa809fb11806) имеют почти одинаковые контроли.

Изменение RMSE лучшей модели относительно среднего, %, [95 % CI]:

| таргет | исследований | кластеры A399 | кластеры по группам авторов |
|---|---|---|---|
| урожай | 76 | −5,1 [−11,0; +2,7] (Ridge) | −3,1 [−7,9; +3,7] |
| сухая биомасса | 172 | −0,8 [−2,6; +0,9] | +0,2 [−2,2; +3,3] |
| **содержание хлорофилла** | 94 | +2,6 [−5,3; +11,7] (RF) — **хуже среднего** | +1,4 [−6,1; +9,2] |
| индекс хлорофилла (SPAD и др.) | 55 | −25,0 [−34,9; −3,2] (RF) | **−10,9 [−15,4; −3,6]** |

Рисунок `figures/c09_cv_three_targets.png`, все модели — `results/c09_comparison_three_targets.csv`.

**Выводы.**
1. **Содержание хлорофилла** по описанию опыта предсказывается не лучше среднего, как и биомасса. Больше однородность эффекта не дала: разброс между исследованиями (τ трёхуровневой модели около 0,3) такой же, как у биомассы. Ниже он только у урожая (около 0,5).
2. **Индекс SPAD** — единственный таргет, где модель статистически лучше среднего. Однако:
   - при строгой группировке выигрыш падает с 25 % до 11 %;
   - 79 % выигрыша дают 3 исследования;
   - без них выигрыш около 6 %, улучшение есть у 33 из 55 исследований.
   Сигнал идёт в основном от типа стресса: при жаре и биотическом стрессе эффект на SPAD выше. Результат осторожно-положительный, его нужно проверить на тесте.
3. Утечка между работами одной группы авторов завышает метрики. Для всех таргетов основным стоит считать строгий вариант группировки.
