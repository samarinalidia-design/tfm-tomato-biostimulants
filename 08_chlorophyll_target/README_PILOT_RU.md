# Пилот: содержание хлорофилла как новая целевая переменная (50 исследований TRAIN, 2026-11-22)

Цель пилота — проверить на 50 исследованиях, можно ли надёжно извлечь содержание хлорофилла из 399 статей A399, сколько это стоит и годятся ли данные для синтеза. Замороженные базы не менялись.

## Схема

Выбор исследований: `scripts/c02_select_pilot.py`.
- 50 из 152 исследований TRAIN с хлорофиллом, стратифицированно, seed 20261122.
- 45 исследований с готовым дизайном A399, 5 без дизайна.
- SHA-256 всех 50 полных текстов совпали с базой.

Пакет исследования: `scripts/c03_packets.py`. В нём:
- файлы-оригиналы;
- места хлорофилла в статье по инвентарю;
- проверенные варианты опыта из A399.

Инструменты агентов: `scripts/chl.py`.
- Отрисовка страницы с квитанцией источника.
- Текст страницы.
- Векторный разбор рисунка.
- Сетка и уточнение края.
- Калиброванная оцифровка по ≥ 3 делениям оси: функции `tfmlib.figures` системы A399.
- Проверка схемы.

Протокол: `docs/EXTRACTION_PROTOCOL.md`.

Порядок работы:
1. Два независимых прохода, A и B: по 10 агентов на 5 исследований каждый.
2. Сверка кодом: `scripts/c04_reconcile.py`.
3. Разбор расхождений по PDF агентами-арбитрами: 4 агента, 16 исследований.
4. Контрасты: `scripts/c05_contrasts.py`.

**Пригодные данные.** В 34 из 50 исследований есть контраст «стресс + биостимулятор / стресс» для общего хлорофилла: 198 контрастов, из них 134 с a + b, посчитанным кодом. Ещё в 9 исследованиях есть только индекс (SPAD), всего 43 из 50.

Если масштабировать на 152 исследования TRAIN, это около 100 исследований — больше, чем для урожая (76).

**Предварительный синтез.** Модель DerSimonian–Laird на средних по исследованию, без учёта зависимости и общих контролей. Это ориентир, а не результат.

| контраст | исследований | эффект, % [95 % CI] | 95 % PI | τ |
|---|---|---|---|---|
| общий хлорофилл, SB vs S | 34 | **+38 [+29, +48]** | −6 … +104 | 0,19 |
| общий хлорофилл, B vs C | 27 | +22 [+10, +35] | −28 … +106 | 0,26 |
| общий хлорофилл, S vs C (ущерб от стресса) | 32 | −34 [−43, −23] | −71 … +53 | 0,42 |
| SPAD, SB vs S | 10 | +24 [+16, +31] | +3 … +49 | 0,09 |

Для сравнения: у урожая τ ≈ 0,44, а прогнозный интервал для нового исследования составляет −40 … +250 %. Хлорофилл выглядит однороднее. Это нужно подтвердить трёхуровневой моделью на полном наборе.

## Трудоёмкость

- Около 140–190 тысяч токенов на агента прохода (5 исследований) и около 100–190 тысяч на арбитра.
- В сумме около 3,8 млн токенов на 50 исследований, примерно 75 тысяч на исследование.
- Время по часам — около 1,5 часа при параллельной работе.
- Полный набор (152 TRAIN + 25 TEST) оценивается в 13–14 млн токенов.

## Что исправить перед полным прогоном

1. **Временные файлы агентов.** Агенты писали вспомогательные скрипты в общую временную папку и перезаписывали файлы друг друга. В одном случае отрисовка ушла в папку чужого прохода. На данные это не повлияло: агент повторил отрисовку, а изображение страницы одинаковое. Нужна отдельная временная папка для каждого прохода и агента.
2. **Пропуск исследования.** Один агент пропустил одно исследование из пяти. Нужна автоматическая проверка полноты после каждой группы.
3. **Список исследований.** Числовые ID (например, «4», «259») агенты путали с числами. Списки исследований нужно давать с явными разделителями.
4. **Сверка.**
   - Нужно сравнивать `during_stress`.
   - Нужно сопоставлять несформулированные сроки (уже сделано вторым этапом).
   - Новые варианты опыта нужно закрепить заранее, чтобы оба прохода использовали одни ключи.
5. **Правила протокола.**
   - Как кодировать «arbitrary units» без названного прибора.
   - Как обращаться со столбиками a и b, сложенными в одну колонку.
   - Как обращаться с исходной точкой до начала стресса, общей для всех вариантов.
