# V7: можно ли поднять метрики на TRAIN изменением базы и предобработки (2026-11-22, разведочный анализ)

Главная цель ТФМ (раздел 2.4) — предсказать относительный эффект на урожай по признакам, известным до опыта, точнее среднего, при валидации, сгруппированной по исследованиям. V7 проверяет, мешали ли этому структура базы, фильтры и кодирование признаков.

**Схема проверки:**
- Используется движок кросс-валидации V5 без изменений:
  - вложенная CV, 5 × 3 фолдов, группы — кластеры зависимости;
  - сиды 11/22/33;
  - веса ivw_re.
- Внешние фолды одинаковы для всех вариантов.
- **Все варианты оцениваются на одних и тех же строках:** `in_default_v6`, 694 контраста урожая. Варианты меняют только то, на чём модель обучается. Поэтому улучшение нельзя получить, убрав трудные строки из оценки.
- Неопределённость: бутстреп по исследованиям, 2000 повторов.
- TEST не использовался.

## Скрипты

| скрипт | что делает |
|---|---|
| `scripts/v7_01_build.py` | Возвращает исключённые данные урожая и добавляет новые признаки (ожидаемая потеря от стресса по FAO, структурные нули, режим удобрения и др.). |
| `scripts/v7_02_cv.py` | Сравнивает данные V5/V6, очистку обучения, возвращённые данные, наборы признаков (REF, компактный, плотный), модели Ridge/RF/мета-регрессия и схемы весов. |
| `scripts/v7_03_ablation.py` | Абляция групп признаков: убрать группу / оставить только группу. |
| `scripts/v7_04_env_probe.py` | Что именно работает в блоке условий опыта: значения или факт их сообщения. |
| `scripts/v7_05_env_v6fill.py` | Тот же блок, заполненный значениями, которые V6 восстановил из текста базы. |

## Абляция: какие признаки дают сигнал, а какие шумят (Ridge, V6)

**Дают сигнал** (без группы RMSE растёт, интервал не включает 0):
- **Числовые условия опыта** (pH и органика почвы, широта, температура, влажность, PPFD, фотопериод, объём горшка, густота): +0,014 [0,003; 0,026]. Одних их с определением исхода хватает на −4,2 % к среднему [CI < 0].
- **Доза, ранг дозы в исследовании, число обработок:** +0,010 [0,003; 0,017].
- **Страна:** +0,002 [0,0005; 0,003].

**Шумят** (без группы лучше, но интервал включает 0):
- числовые описания стресса (ПВ, NaCl, EC, длительность);
- флаги типа продукта;
- строки единиц измерения.

**Ровно 0** — текстовые категории: состав, класс, штамм, сорт, сезон, почва, удобрения, патоген. Ни один их уровень не набирает 3 исследования, поэтому кодировщик их выбрасывает.

**Блок условий опыта, подробно** (`v7_04`, `v7_05`):
- одни значения без индикаторов пропуска: −3,1 %;
- одни индикаторы «сообщено / не сообщено»: −0,3 %;
- ни одна переменная не даёт сигнала в одиночку.
- **Если заполнить блок полнее и правильнее** (V6: широта 9 % → 38 %, температура 11 % → 26 %, влажность 4 % → 18 %), сигнал исчезает: −4,2 % → +1,4 %, разница +0,028 [0,001; 0,053].
- Модель опиралась не на агрономический смысл переменных, а на то, какие исследования напечатали точные числа и какие именно. Это отпечаток конкретных обучающих исследований, он не переносится на новые.
- Это согласуется с двумя фактами V5: Ridge на TEST не лучше среднего; без UNSPECIFIED-урожая выигрыш исчезает.

## Результаты: биомасса

- Ни один вариант не лучше трёхуровневого среднего MR0 (RMSE 0,3625).
- V6 улучшает Ridge (0,396 → 0,391), но он остаётся на 7,5 % хуже среднего.
- Плотный набор без весов равен среднему.

## Вывод

1. **Исправления базы (V6) реально улучшают модель.** Это единственное изменение данных со значимым эффектом.
2. **Опасения о предобработке подтвердились, но их исправление метрик не поднимает:**
   - Правила «≥ 20 % исследований» в V5 уже нет.
   - Правило «≥ 3 исследований» действительно обнуляет все текстовые поля. Однако их гармонизированные числовые версии (флаги состава, таксонов, удобрений, почвы, TF-IDF и target encoding в V5) сигнала тоже не дают.
   - Ослабление фильтров (+9 исследований) не помогает.
3. **Видимый выигрыш ML над средним (−4…−5 %) статистически не надёжен** (CI включает 0) и держится на неполноте отчётности. По описанию опыта до эксперимента эффект на урожай в этих данных не предсказывается лучше среднего. Это ответ на главный вопрос работы, а не следствие ошибки базы.
4. **Что реально может помочь:**
   - больше исследований: кривая обучения V5 продолжает снижаться;
   - стандартизированная отчётность об условиях опыта и силе стресса;
   - условное предсказание по наблюдаемому ущербу от стресса (категория B в V5; ущерб измеряется в самом опыте).

Все результаты лежат в `results/`.

## Дополнение: правильно закодированный текст (`scripts/v7_06_text_parsed.py`)

**Вопрос:** сырые текстовые поля дают 0, потому что ни один их уровень не набирает 3 исследования. А что даёт тот же текст, разобранный в переносимые между исследованиями признаки?

**Схема:** к набору без текста (REF_CLEAN) по одному добавлялись блоки разобранного текста (тексты V5: `07_features_v2`, `11_features_v3`). Затем всё вместе, кодирование целевой переменной по категориям (TE) и TF-IDF. Данные, фолды и строки оценки те же; Ridge, 3 сида. Блоки покрывают 71–100 % исследований.

Δ — изменение RMSE к REF_CLEAN; отрицательное значение лучше, в скобках 95 % CI.

| блок | Δ RMSE | Δ к среднему |
|---|---|---|
| REF_CLEAN (текст выброшен) | 0 | −4,8 % |
| + фаза внесения и начала стресса | +0,000 [−0,006; +0,006] | −4,8 % |
| + сезон (месяц, год, тёплый сезон) | **+0,007 [+0,001; +0,012]** | −3,4 % |
| + генотип (мелкоплодный, для переработки, гибрид, толерантность) | +0,009 [−0,002; +0,021] | −3,0 % |
| + состав продукта (флаги таксонов и действующих веществ, род) | +0,013 [−0,000; +0,029] | −2,0 % |
| + почва и удобрения (песок, глина, N кг/га, режим) | +0,013 [−0,000; +0,031] | −2,0 % |
| весь разобранный текст | **+0,031 [+0,011; +0,051]** | +1,7 % |
| весь текст + TE | +0,024 [−0,004; +0,057] | +0,3 % |
| весь текст + TF-IDF | **+0,028 [+0,008; +0,049]** | +1,1 % |
| RF: без текста / весь текст | 0,4526 / 0,4628 | −3,3 % / −1,1 % |

**Вывод.** Правильно закодированный текст не несёт переносимого сигнала: каждый блок ухудшает прогноз, все вместе — значимо. Разобранные поля добавляют десятки признаков. На ~60 обучающих исследованиях эти признаки различают сами исследования, а не биологию. То, что текст «не попадал в модель», не было причиной неудачи.

## Дополнение: биомасса — возраст, отдельные модели по органу, веса (`scripts/v7_08_biomass.py`)

**Схема:** данные V6, те же фолды и строки оценки, 3 сида, бутстреп по исследованиям.

Δ — изменение RMSE к варианту V5 (REF без текста, веса 1/(v+τ²), Ridge); отрицательное значение лучше, в скобках 95 % CI.

| вариант | RMSE | Δ | к среднему |
|---|---|---|---|
| вариант V5: REF без текста, веса 1/(v+τ²), Ridge | 0,3900 | 0 | +7,1 % |
| **без весов** | 0,3721 | **−0,018 [−0,032; −0,005]** | +2,2 % |
| равный вес каждого исследования | 0,3907 | +0,001 | +7,3 % |
| возраст с явной точкой отсчёта, без весов | 0,3739 | −0,016 | +2,7 % (возраст сам по себе не помог) |

| то же + возраст | 0,3700 | −0,020 | +1,6 % |
| RF, без весов | 0,3731–0,3757 | — | +2,5…+3,2 % |
| среднее по органу | **0,3622** | — | −0,5 % |

**Вывод:**
- Отказ от весов по точности — значимое улучшение. Именно веса делали ML на 7 % хуже среднего: из-за эффекта малых исследований взвешенная модель смещается к точным контрастам.
- Отдельные модели по органу немного добавляют.
- Явное кодирование возраста не помогает.
- Отставание от среднего сократилось с +7 % до +1,4 %, но обойти среднее не удалось. Лучший простой прогноз биомассы — среднее по органу.
