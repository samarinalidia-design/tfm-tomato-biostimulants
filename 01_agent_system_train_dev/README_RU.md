# Система агентов TFM категории A версия 2 2

Действующий контракт: базовое ТЗ v2 плюс **docs/BINDING_ADDENDUM_2_2_RU.md**, закрепляющее прямые указания автора от 19 октября.

Начните с **INSTALL_RU.md** или документа установки в папке **docs**. После подготовки источников и запуска `tools/bootstrap.py` рабочая команда в Claude Code — **/tfm-finalize**.

Пакет предназначен ровно для 399 зафиксированных study_id. Входной реестр содержит 462 оригинала; Docling имеет статус UNVERIFIED. Критичные данные и используемые модераторы независимо проверяются по оригинальным PDF и supplementary. Omics-матрицы и нерелевантные панели не заполняются. Исходный корпус остаётся только для чтения.

Установка создаёт локальную SQLite и очередь, а не объявляет научную финализацию выполненной. Готовность определяется текущими release gates и человеческим аудитом по TFM. Подтверждённые mean-only targets остаются доступны для ML; метаанализ с весами использует отдельные A_meta_*_weighted.

Содержимое:

- `.claude/agents` — 12 специализированных ролей; дополнительные виды проверки используют эти же роли в отдельных независимых запусках.
- `.claude/skills` — запуск, установка, статус, review, export и автономная финализация.
- `config`, `schema`, `tools` — контракты, валидаторы, очередь, расчёты и проверяемый выпуск.
- `manifests` — замороженные 399 ID и 462 источника.
- `docs` — актуальное ТЗ, инструкция, исходный текст TFM и фактические результаты проверок.
- `tests` — синтетические регрессионные сценарии и явно искусственные legacy fixtures.

Новая версия начинает работу из исходного Excel. Не переносите db/work из v1: прежняя ошибка record_key могла уже перезаписать данные между статьями. Существующие корректные знания и источники сохраняются в исходном импорте; в verified слой они попадают после проверки.

Полный реальный прогон 399 статей и итоговый человеческий аудит ещё не выполнены. Испытания кода не являются оценкой точности извлечения реальной литературы.

В v2.1 обязательна оцифровка видимых error bars. Необозначенные планки считаются SE с USER_ASSUMED_SE, источник не переименовывается в reported SE. Погрешность оцифровки не выше 5%; точные напечатанные числа не получают такой допуск. Два проверенных Excel имеют одинаковые значения и формулы на 27 листах; приняты оба конкретных хэша, а не произвольная новая книга.

В v2.2 дополнительно устранён риск прежней ориентации на биомассу: все 399 статей получают новую инвентаризацию оригиналов под урожайность. Отсутствующая или неясная урожайность независимо перепроверяется даже при найденной биомассе. Повторный пакет не содержит прежних выводов, извлечённых таблиц Docling и инвентаря. Поиск смысловой: harvest, fruit production, productivity и другие названия являются подсказками, а не закрытым словарём.
