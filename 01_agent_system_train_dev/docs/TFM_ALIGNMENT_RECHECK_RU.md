# Повторная сверка с TFM 19 октября 2026

Прочитан актуальный TFM_Agrobiologia_Ambiental непосредственно на Google Диске. Цели §2.1–2.5, правила §3.1–3.11, §3.13–3.19 и Annex B/C сопоставлены с конфигурацией, схемами, prompts и исполняемым кодом.

| Требование проекта | Решение в пакете |
|---|---|
| Fruit yield SB/S primary | Отдельный A_direct_yield, исходная масса/деноминатор/период сохраняются |
| Terminal dry biomass secondary | Отдельный A_direct_dry_biomass; whole plant прежде shoot, root отдельно |
| Interactions | Только полный сопоставимый факторный дизайн; зависимости и variance учитываются |
| Релевантные модераторы | Генотип, система, физический стресс, состав/доза/внесение, timing; availability до воздействия |
| Статистика и lineage | Source-linked means/uncertainty/n; биологические единицы; отдельные исходные и derived слои |
| До ML | SQLite/Excel/CSV/Parquet, словарь/policy/QA, 8 data-stage figure groups; ML и будущий TEST не выполняются |
| Новые указания автора | Самостоятельная сверка; видимые error bars; 5%; SE-default с явной пометкой |

Существенные исправления v2.1: обязательный per-point учёт error bars вместо прежнего предупреждения; геометрический bound и независимая проверка; допущение USER_ASSUMED_SE, не подмена reported type; более подробные audit evidence; field-level дополнение точного среднего погрешностью с отдельной provenance; source conflict направляется агенту арбитража. Необозначенный тип сам по себе не создаёт вопрос человеку.

Документ TFM по научному содержанию совпадает с сохранённым текстом v2; различаются только маркеры списков при чтении другим интерфейсом. Рабочий Excel изменился как файл, но значения и формулы на всех 27 листах идентичны. Проверены одинаковые 399 study IDs и 462 file IDs. Сравнения сохранены в BASELINE_COMPARISON_2026-10-19.json и FORMULA_COMPARISON.json. Рабочий импорт содержит 312 непустых experiments; это число не приравнивается к физическому числу строк листа.

Оставлен финальный человеческий аудит из TFM §3.10. Он не означает ручную проверку каждой цифры корпуса. Пакет готовит одну стратифицированную выборку с исходными представлениями всех плеч и допущениями. Полный прогон 399 не выполнен; научную готовность базы сейчас не заявляем.

Источник: https://docs.google.com/document/d/1A6AXVUVX4p9s0GrX0uzuo2SX5J7IFnmTbl9eLZcl5A4/edit?usp=drivesdk

Среда реализации отличается от описанного в TFM варианта ChatGPT Business/Jupyter: поставляемый агентный пакет работает в Claude Code с Python CLI. В журнале должны сохраняться фактически использованные provider/model/runtime и версии; при оформлении Methods следует описывать реальное исполнение, а не приписывать его ChatGPT. Научные критерии, scope и запрет ML на этой стадии сохранены.

Дополнение v2.2 учитывает историю смены таргета: полнота старого извлечения урожайности UNKNOWN, новая инвентаризация оригиналов обязательна для всех 399, отсутствие primary независимо проверяется даже при биомассе. Harvest и другие термины служат открытым смысловым поиском; исходное определение и единицы имеют приоритет над совпадением слов.
