# Изменения версии 2 1

Повторная сверка выполнена с живым TFM на Google Диске и прямыми указаниями автора от 19 октября.

- Средние и видимые планки погрешности обязательны; пропуск координат не закрывается предупреждением.
- Для необозначенных планок действует SE с USER_ASSUMED_SE, отдельно от reported type.
- Для среднего и ширины error bars проверяется геометрическое разрешение до 5%; сохраняются отдельные границы и односторонние caps.
- Добавлены render 360/600 dpi с отдельными receipts и автоматический RECHECK_FIGURE для независимых повторных проходов.
- Точные табличные means могут дополняться проверенной графической uncertainty с отдельной provenance, нормализацией единиц и проверкой n. При расхождении сначала работает агент арбитража.
- Допущение SE видно в arms, контрастах, marts и audit.xlsx; sensitivity без допущения задаёт отдельный eligibility-флаг.
- Два конкретных Excel приняты после проверки равенства значений и формул всех 27 листов. Frozen 399 и source manifest 462 неизменны.
- Итоговый прогон: 63 теста, 0 ошибок, 0 пропусков. Полного real-source прогона 399 пока нет.

| Область | Исправление |
