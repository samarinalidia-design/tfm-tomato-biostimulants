### B. Правила для TRAIN и TEST

**B1. Восстановлены исправления V3.1, потерянные в V5:**
- исключены «биостимуляторы», которые на деле питательная среда без бактерий, NPK или растворитель (D_1c707674, 653, 706);
- три контраста биомассы пересчитаны против правильного контроля.

**B2. Числа из текста базы.**
- Разбираются форматы «25 ± 5», «20–25», недели → дни (решение D2), растения/га → /м², расстояние между рядами и растениями, градусы-минуты-секунды, 16/8 ч.
- Значения заполняются только там, где в V5 пусто. Берётся значение своего варианта, затем своего опыта, затем всей статьи. Из другого опыта значения не переносятся.
- Наблюдения после обработки (OBSERVED_POST_TREATMENT) не используются.

**B3. Один контраст на пару вариантов и сбор.** Порядок выбора:
1. свежая масса, а не сухая;
2. полный сбор, а не ранний;
3. TOTAL, затем UNSPECIFIED, затем MARKETABLE;
4. целое растение, а не побег;
5. STRICT, затем ASSUMED, затем BROAD;
6. на растение, а не на площадь.

Раньше одна пара входила в обучение 2–3 раза: 136 лишних строк урожая и 138 биомассы в TRAIN.

**B4. Реализованный стресс** `v6_stress_realisation`, по ln(S/C) собственного контроля без стресса:
- NOT_REALISED: ≥ −0,05;
- MILD;
- REALISED;
- SEVERE_CONTROL_LT_25PCT;
- NO_UNSTRESSED_REFERENCE.

Флаг TARGET_QUANTIZED ставится, если все средние целые и различных значений не больше двух.

**B5.** Подвой и прививка из текста генотипа варианта.

**B6.** Возраст при измерении `v6_age_days` с точкой отсчёта `v6_age_reference`: после посева, после пересадки, от начала стресса, после инокуляции, отсчёт не указан.

**B7.** Азот, кг/га, из текста удобрений (федданы делятся на 0,42).

### C. Наборы

- `in_default_v6` = `in_default` V5 после B1 и B3.

## Ограничения

- **Ядро качества — анализ чувствительности, а не замена основного набора.** Исключение погибших контролей механически убирает самые большие эффекты.
- **Реализованный стресс (ln S/C) измерен после опыта.** Для мета-регрессии он допустим. В прогнозе его нужно подавать как ожидаемую потерю урожая.
- **Модели V5 не переобучались, MODEL_FREEZE_V5 не менялся.** TEST уже использовался, поэтому любая новая оценка на нём — POST_HOC_TEST_REUSE.
- **Таблицы V5 `*_SvsC` и `*_interactions` в V6 не пересобраны.**
- **Без нового чтения PDF не восстановить:**
  - NPK почвы;
  - число сборов и длительность сезона;
  - объём полива;
  - действующие вещества препаратов;
  - поражённость в контроле при биотическом стрессе.

  Покрытие кг N/га остаётся около 11 %, густоты около 23 %. Для этого нужно целевое дочитывание статей всех 76 исследований урожая и 172 биомассы.
- **Статьи TEST по PDF не сверялись.** К ним применены только правила B.
