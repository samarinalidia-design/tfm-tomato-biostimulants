# TFM_TRAIN_EXPANSION — версия V5 (2026-11-20)

Первичный исход — урожай плодов (lnRR), вторичный — сухая биомасса (побег / целое растение).
Входы только читались и не изменялись:
- TRAIN — `DATA_FREEZE_20261113T112939135807Z` (TRAIN_DEV, 399 исследований);
- TEST — `TFM_TEST_2024_2026_Agent_System/exports/DATA_FREEZE_20261118T105532769144Z` (EXTERNAL_TEST, 2024–2026).

Все исправления сделаны в обучающих и тестовых таблицах V5, а не в базе.

## Исправления (реестр `data/corrections_register.csv`)

**Размерные фракции, ошибочно помеченные TOTAL (D_8a246bc169c4b812 и 112).**
- Таблицы источника дают урожай по фракциям Small/Medium/Large (кг/10 растений).
- В V5 фракции суммированы в общий урожай по средним тех же растений. SD не складывались (не сообщены, ковариация фракций неизвестна), дисперсия импутирована.
- Взаимодействие A×B пересчитано из сумм.
- Общий контроль обоих исследований подтверждён (связь SHARED_CONTROLS, один `dependency_cluster_id` DC-112).

**Привязка года к измерению (717).**
- Значения таблицы 3 сверены с изображением страницы, все 54 строки совпадают со своими годами.
- Год измерения теперь берётся из ключа срока (2018/2019), а не из года публикации (2021). Сезоны стали отдельными экспериментами E1_2018 и E1_2019.
- «Green yield» (недозрелые плоды) — это фракция, а не урожай; 18 контрастов исключены.

**Классификация стресса.**
- Исправлены ошибки правил V4:
  - `ht_` срабатывало на `drought_`;
  - «nutrient solution» считалось стрессом питания;
  - «wilting» — болезнью.
- Добавлен класс COMBINED (≥ 2 семейств стресса).
- D_9f55f313bda6b2a2 (альтернариоз), D_dd7c82f0d09468db и D_78e9f6919306e144 → BIOTIC.
- Наночастицы металлов и бензойная кислота → CHEMICAL_TOXICITY.
- Сточные воды → COMBINED (засоление + металлы).
- В исследовании 41 варианты полного полива, ошибочно закодированные как стресс, переведены в B_vs_C.
- Всего класс стресса изменился у 11 исследований урожая.

**Спорный случай (112).**
- Авторы называют почву засолённой, но EC 1,2 мСм/см ниже порога для томата (~2,5 дСм/м).
- Контроль численно совпадает с нестрессовым контролем D_8a246…
- Контраст переведён в B_vs_C с флагом `STRESS_RECLASSIFIED_NONE_DISPUTED`; заявление авторов сохранено в `v5_stress_declared`.

**Гибридность.** Неизвестная гибридность больше не кодируется как 0. HYBRID ставится только при явном hybrid/F1, OP — только при явном open-pollinated/landrace. Иначе UNSPECIFIED или NaN; это затронуло 42 исследования.

**Без изменений по смыслу:**
- неизвестный сорт остаётся UNSPECIFIED;
- широта по центру страны помечена COUNTRY_CENTROID;
- отсутствующие данные не придумывались.

**Дубли признаков во входах моделей.** Точные дубли и константные столбцы определяются на обучающих строках каждой подгонки и удаляются (`results/v5_feature_duplicates_audit_*.csv`). Примеры дублей: `h_n_applications` = `f_n_applications`, `h_stress_class==NONE` = `is_B_vs_C`, `yield_tier==DRY` = `mass_basis==DRY`.
