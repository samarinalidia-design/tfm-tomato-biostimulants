## 3. Задача 2 — импутация дисперсии (Nakagawa et al., 2023)

### Правила

1. **CV = SD/mean** считается только при mean > 0. SD берётся **только** из SD/SE, напечатанных авторами (`dispersion_basis = SOURCE_REPORTED`). USER_ASSUMED_SE не используется.
2. CV усредняется сначала **внутри исследования**, затем **по исследованиям с весом n**, отдельно для каждого показателя.
3. Дисперсия контраста: **var = CV_t²/n_t + CV_c²/n_c**. Для группы с известным CV берётся её собственный CV, для остальных — CV̄. Если n не указан, берётся медианное n.
4. Если в исследовании напечатан CV% или LSD, используется он (CV% — напрямую; LSD пересчитан в SD при известном n).
5. Исходная дисперсия сохранена в `var_effect_original`, исходный bias-corrected эффект — в `effect_bc_original`.
6. Флаги: `VARIANCE_IMPUTED_MEAN_CV`, `N_IMPUTED_MEDIAN`. Источник по каждой группе записан в `cv_source_t/c`, итоговый статус — в `variance_status`.

### Итоги (`results/variance_imputation_summary.csv`)

| | урожай | биомасса |
|---|---|---|
| групп всего / с SD авторов | 1260 / 411 | 2088 / 1059 |
| исследований с SD авторов / всего | 32 / 79 | 95 / 172 |
| **CV̄** (взвешенный по n) | **0.290** | **0.275** |
| медиана CV по исследованиям [p05; p95] | 0.104 [0.033; 0.586] | 0.130 [0.039; 0.282] |
| медианное n | 4 | 4 |
| контрастов: дисперсия по SD/SE авторов | 264 | 678 |
| контрастов: CV̄ (VARIANCE_IMPUTED_MEAN_CV) | 574 | 741 |
| контрастов: CV% / LSD исследования | 18 / 0 | 27 / 35 |
| контрастов с N_IMPUTED_MEDIAN | 93 | 349 |

> **Важно.** Подставленная дисперсия — это **оценка**, полученная по среднему CV других исследований. Авторы её **не сообщали**. В таблицах она всегда помечена флагом `VARIANCE_IMPUTED_MEAN_CV` или `N_IMPUTED_MEDIAN`, а колонка `variance_from_author_sd` = 0.

### Ограничения импутации

- **CV̄ смещён вверх.** CV̄ урожая 0.29 почти втрое больше медианы CV по исследованиям (0.10). Взвешенное среднее тянут вверх несколько исследований с очень высокой вариабельностью. Поэтому импутированные контрасты получают *меньший* вес, чем получили бы при «типичном» CV. Это консервативно, но в одну сторону.
- **Медианное n = 4** — допущение. Если реальные n больше, дисперсия завышена.
- **Зависимость между контрастами не моделируется.** Предполагается независимость групп, хотя один контроль часто служит нескольким обработкам. Частично это учитывают трёхуровневая модель и кластерно-робастные SE.
- **I² зависит от импутации.** Типичная дисперсия v мала (0.005), поэтому I² ≈ 97%. Если всем группам подставить CV̄ (вариант `IMPUTATION_meanCV_all_groups`), I² падает до 83%. Значит, оценки I² чувствительны к способу импутации; τ² намного устойчивее.

## 5. Задача 3 — кросс-валидация: все модели и все варианты

### Схема и модели

- Модели:
  - базовые: обучающее среднее (`BASELINE_mean`), взвешенное среднее;
  - трёхуровневые MR0 / MR1 / MR2;
  - RF с весами 1/(v+τ²) в стиле MetaForest;
  - взвешенный GBM;
  - Ridge.
- Признаки — только роль FEATURE из `feature_policy.csv`. Пост-факторных исходов среди них нет (проверено `assert`).
- Метрики:
  - точность: RMSE, MAE, R² и взвешенный RMSE (веса 1/(v_imp + τ²_ref));
  - интервалы: покрытие 95%-интервалов и их ширина. Для ML это conformal-подобный интервал по внутренним OOF-остаткам, для MR — модельный.
- Сиды:
  - DEFAULT — 3 сида × 2 схемы;
  - TARGET_effect_bc — 3 сида;
  - остальные варианты — 2 сида.

Всего 64 прогона (`results/cv_metrics_all_runs.csv`).

### 7.6. Раунд 4 — складываются ли улучшения

- мультизадача урожай + биомасса (`_MULTITASK`, см. ниже);
- MR2 с du Jardin v2;
- стеки — **равновесное среднее** заранее выбранных моделей. Веса фиксированы, на валидационных строках ничего не подбиралось. Интервал стека — среднее полуширин компонентов (приближение).

Как устроена мультизадача без утечки. Из обучения убираются все строки отложенных исследований по обоим показателям: в фолде нет ни урожая, ни биомассы проверяемого исследования.

Это допустимо по ТЗ (S_vs_C — модератор мета-регрессии; в ML-модели как признак не подаётся). Но такой прогноз возможен, **только если для нового исследования уже известен эффект стресса на контроле**. Сравнивать B с A напрямую как «улучшение ML» нельзя.

**2. Числовые кодировки, обучаемые только внутри обучающего фолда** (и внутри внутренних фолдов при подборе гиперпараметров).
- **Target encoding** ключей с высокой кардинальностью: класс препарата, сорт, страна, ведущий род, du Jardin, тип стресса. Значение уровня — среднее по исследованиям, сжатое к общему среднему: (n_исслед·m + 5·m_общ)/(n_исслед + 5). Обучающие строки получают значения out-of-fold по 5 группам исследований, поэтому строка никогда не видит цель своего исследования.
- **Частотное кодирование:** log(1 + число исследований с уровнем).
- **TF-IDF + SVD (10 компонент)** по объединённому тексту (препарат, организм, способ, система, субстрат, стресс). Один документ на исследование; термины, встречающиеся в ≥ 3 обучающих исследованиях.

**Наборы признаков.** Модели: Ridge и RF; GBM исключён как самый слабый в раундах 1–4. Стеки равновесные и заданы заранее: A = Ridge + RF; B = Ridge + MR2 мультизадачная. Сравнение парное, 3 сида.
- `REF_V2DJ` — текущий лучший набор;

1. **Биомасса.** Перекодировка в числа — самое сильное улучшение ML-моделей за проект: Ridge −5.8%, RF −3.4%, стек A −4.4% к REF. Лучше всего работают компактные кодировки: target encoding и TF-IDF/SVD. Они сжимают сотни уровней в несколько чисел. Простое добавление флагов (V3_PARSED) даёт меньше, около 2%. 3. **Ошибки или утечки не видно.** Утечка улучшила бы метрики, а не ухудшила. Набор REF воспроизведён точно. Ухудшение у урожая систематическое по сидам и моделям.

Выбирать подмножество блоков h3 для урожая по этим же результатам CV нельзя: это была бы подгонка под валидацию. Корректный путь — отбор блоков внутри внутренней CV (п. 9).

### 7.8. Раунд 6 — отбор блоков v3 для урожая внутри внутренней CV

Скрипт `scripts/13_round6_block_selection.py`. Те же внешние фолды по исследованиям и сиды 11/22/33.

**Процедура.** В каждом внешнем обучающем фолде старт — набор REF_V2DJ. Кандидаты — 11 блоков: TAXON, ACTIVE, ROUTE, STRESS, PHASE, SOIL_FERT, SEASON, GEO, GENOTYPE, TE (target encoding), TFIDF. Прямой жадный отбор: каждый блок оценивается внутренней CV (3 фолда по исследованиям, только обучающие исследования, взвешенная MSE). Добавляется лучший блок, если он снижает внутреннюю ошибку не менее чем на 1%. Максимум 3 блока. Затем обычный подбор гиперпараметров, переобучение на всём фолде и прогноз на внешней валидации. Валидационные исследования в отборе не участвуют, поэтому оценка относится ко всей процедуре целиком. Для экономии времени RF при отборе оценивался с одной фиксированной регуляризованной настройкой (max_features 0.33, min_samples_leaf 10, 150 деревьев). Финальная модель RF подбиралась по полной сетке.

**Результат (RMSE, среднее по 3 сидам; `results/cv_metrics_round6_summary.csv`):**

| модель | REF_V2DJ | отобранные блоки | Δ |
|---|---|---|---|
| Ridge | 0.440 | 0.469 | **+6.8%** |
| RF | 0.452 | 0.469 | +3.6% |
| стек A (Ridge + RF) | 0.440 | 0.462 | +4.8% |
| стек B (Ridge + MR2 мультизадачная, кат. B) | 0.425 | 0.439 | +3.4% |

Ухудшение воспроизводится на каждом сиде для каждой модели. MR0 — 0.460, среднее — 0.461. Значения REF совпадают с раундом 4.

**Какие блоки выбирались** (`results/round6_selected_blocks.csv`, 15 фолдов × 2 модели):
- Ridge чаще всего выбирал PHASE (10 из 15), затем STRESS, SOIL_FERT, ACTIVE и TE. Наборы разные почти в каждом фолде.
- RF чаще всего выбирал TE (7 из 15) и TFIDF (4 из 15). В 2 фолдах не выбрано ничего.
- Внутренний выигрыш при отборе составлял 1–17%. На внешних исследованиях он не подтвердился ни для одного сида и ни для одной модели.

**Вывод.** Это классический оптимизм отбора на малой выборке. На ~60 обучающих исследованиях разница внутренней ошибки в несколько процентов лежит в пределах шума разбиения. Отбор подстраивается под конкретные обучающие исследования, и состав блоков нестабилен между фолдами. Для урожая v3-признаки не дают проверяемого выигрыша ни целиком (раунд 5), ни при корректном отборе (раунд 6). **Итоговая конфигурация для урожая остаётся REF_V2DJ:** Ridge 0.440 (кат. A), стек Ridge + MR2 0.425 (кат. B).

### 7.9. Раунд 7 — биомасса: признаки v3 с target encoding в составе стеков

Модели в составе точно воспроизводят раунд 5 (Ridge 0.382, RF 0.375, MR0 0.366).

**Веса, выученные внутри CV** (`results/round7_stack_weights.csv`, среднее по 15 фолдам):
